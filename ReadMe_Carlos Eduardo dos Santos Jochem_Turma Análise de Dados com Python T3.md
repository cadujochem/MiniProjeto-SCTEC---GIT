Mini Projeto SC TEC - Analise de Dados com Python do CSV 

Trata-se de um projeto de Estudos para conclusão do Curso de Analise de Dados com Python do SENAI em Parceria com o SCTEC

## 🚀 Tecnologias

Este projeto foi desenvolvido com as seguintes tecnologias:

* Python
* Pandas
* Numpy
  

## 📌 Funcionalidades

Analisa o CSV - Base_Varejo.CSV, Efetua ANalises 

## 📦 Como rodar o projeto

Siga os passos abaixo para rodar o projeto na sua máquina:

Para Rodar o Projeto: Basta Clonar este repositório ou fazer o download do seu conteúdo, 
ao abrir a pasta encontrará o arquivo analise-base-varejo.ipynb. Execute este arquivo no VSCODE com a Extensão Jupiter Notebook 
e inicie executando todas as celulas de comando uma a uma de de cima para baixo.

O arquivo de scripts citado importa os dados do arquivo. base_varejo.csv e efetua Analise Exploratória, Limpeza e 
Tratamentos dos dados com a biblioteca Pandas fornecendo a base de informações para as analises e estatísticas relatadas
no arquivo: analise_conclusao.pdf
