Mini Projeto SC TEC - Analise de Dados com Python do CSV 

Trata-se de um projeto de Estudos para conclusão do Curso de Analise de Dados com Python do SENAI em Parceria com o SCTEC

## 🚀 Tecnologias

Este projeto foi desenvolvido com as seguintes tecnologias:

* Python
* Pandas
* Numpy
  

## 📌 Funcionalidades

O arquivo de scripts analise_base_varejo.ipynb  importa os dados do arquivo . base_varejo.csv e efetua Analise Exploratória, Limpeza e 
Tratamentos dos dados com a biblioteca Pandas e Numpy fornecendo a base de informações para as analises e estatísticas relatadas
no arquivo: analise_conclusao.pdf


## 📦 Como rodar o projeto

Siga os passos abaixo para rodar o projeto na sua máquina:

Você Necessitará do VSCode com a extensão do JupiterNotebook para executar o tipo de arquivo analise_base_varejo.ipynb
Você também necessitará das bibliotecas, Pandas e Numpy instaladas.

Para Rodar o Projeto: Basta Clonar este repositório ou fazer o download do seu conteúdo, 
utilize VSCODE para abrir o Repositório clonado ou a pasta baixada e descompactada 

Após o VSCode aberto na pasta do repositório:
Execute o arquivo analise_base_varejo.ipynb 
e inicie executando todas as células de comando uma a uma 
de de cima para baixo observando os comentários e os retornos de cada comando.
